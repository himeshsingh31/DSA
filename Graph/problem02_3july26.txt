# Cycle Detection in Undirected Graph (BFS + DFS)

---

# Step 1: Create Adjacency List

```cpp
unordered_map<int, list<int>> adj;

adj[u].push_back(v);
adj[v].push_back(u);
```

* Since the graph is **undirected**, store both directions.

---

# Method 1 : BFS Cycle Detection

## Data Structures

```cpp
unordered_map<int,bool> visited;
unordered_map<int,int> parent;
queue<int> q;
```

### Purpose

* **visited** → Has this node been visited?
* **parent** → Stores from which node we reached the current node.
* **queue** → Used for BFS traversal.

---

## Initialization

```cpp
q.push(startNode);
visited[startNode] = true;
parent[startNode] = -1;
```

---

## BFS Traversal

```cpp
while(!q.empty())
```

Remove front node and visit all its neighbours.

---

## Case 1 : Neighbour not visited

```cpp
visited[i] == false
```

Then

```cpp
visited[i] = true;
parent[i] = currentNode;
q.push(i);
```

Meaning:

* Mark visited.
* Store parent.
* Continue BFS.

---

## Case 2 : Neighbour already visited

```cpp
visited[i] == true
```

Now check

```cpp
parent[currentNode] != i
```

If true

➡️ Cycle exists.

Reason:

If the neighbour is visited but is **not** the parent, then we have reached the same node through another path.

---

## BFS Condition

```cpp
if(visited[i] && parent[currentNode] != i)
    return true;
```

---

# Method 2 : DFS Cycle Detection

## Data Structures

```cpp
unordered_map<int,bool> visited;
```

Parent is passed as a function parameter.

```cpp
dfs(node, parent, visited, adj);
```

---

## Visiting a Node

```cpp
visited[node] = true;
```

---

## Case 1 : Neighbour not visited

```cpp
if(!visited[neighbour])
```

Go deeper.

```cpp
if(dfs(neighbour, node, visited, adj))
    return true;
```

---

## Case 2 : Neighbour already visited

If

```cpp
neighbour != parent
```

then

```cpp
return true;
```

Reason:

Neighbour is already visited and is not the node from which we came.

Hence a cycle exists.

---

## DFS Condition

```cpp
else if(neighbour != parent)
{
    return true;
}
```

---

# Handling Disconnected Graph

```cpp
for(int i = 0; i < n; i++)
{
    if(!visited[i])
    {
        ...
    }
}
```

Reason:

The graph may have multiple disconnected components.

Run BFS/DFS from every unvisited node.

---

# Difference Between BFS and DFS Cycle Detection

| BFS                                              | DFS                                     |
| ------------------------------------------------ | --------------------------------------- |
| Uses Queue                                       | Uses Recursion                          |
| Needs Parent Map                                 | Parent passed as parameter              |
| Checks `visited && parent[current] != neighbour` | Checks `visited && neighbour != parent` |
| Traverses level by level                         | Traverses depth first                   |

---

# Time Complexity

```
O(V + E)
```

Each vertex and edge is visited once.

---

# Space Complexity

### BFS

```
O(V)
```

For:

* Queue
* Visited map
* Parent map

### DFS

```
O(V)
```

For:

* Visited map
* Recursion stack

---

# Easy Revision Trick

### BFS

```
Queue
+
Visited
+
Parent Map
```

Cycle if:

```
Visited && Parent != Neighbour
```

---

### DFS

```
Recursion
+
Visited
+
Parent Parameter
```

Cycle if:

```
Visited && Neighbour != Parent
```

---

## Memory Trick

* **BFS**: *"Remember the parent using a map."*
* **DFS**: *"Carry the parent in the recursive call."*

Both use the same idea: **if you encounter an already visited node that is not the parent, a cycle exists.**



#include<unordered_map>
#include<list>
#include<string>
#include<queue>
bool bfs(int n,unordered_map<int,list<int>>&adj,unordered_map<int,int>&parent,unordered_map<int,bool>&visited){

queue<int> q;
q.push(n);
parent[n]=-1;
visited[n]=1;
while(!q.empty()){
int x = q.front();
q.pop();

for(auto i:adj[x]){

if(visited[i]==1 && parent[x]!=i){
    return true;
}
else if(visited[i]==0){
    q.push(i);
    visited[i]=1;
parent[i] = x;
}
}

}
return false;

}

bool dfs(int node,int parent,unordered_map<int,bool>&visited,unordered_map<int,list<int>>&adj){

visited[node] = true;

for(auto neighbour:adj[node]){
if(!visited[neighbour]){
    bool x = dfs(neighbour,node,visited,adj);
    if(x==true){
        return true;
    }
}
else if(neighbour!=parent){
    return true;
}

}
return false;
}
