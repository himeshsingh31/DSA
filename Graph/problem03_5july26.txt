bool dfscycle(int node,unordered_map<int,bool>&visited,unordered_map<int,bool>&dfstr,unordered_map<int,list<int>>&adj){

visited[node] = true;
dfstr[node] = true;

for(auto j:adj[node]){
  if(!visited[j]){
bool x = dfscycle(j,visited,dfstr,adj);
if(x ==true){
  return true;
}
  }

  else if (visited[j] && dfstr[j]==1){
return true;
  }

}
dfstr[node]=false;
return false;
}

# DFS Cycle Detection in Directed Graph (My Code)

### 1. Data Structures

* Stores adjacency list.
* Since the graph is **directed**, add only:

```cpp
adj[u].push_back(v);
```

---

```cpp
unordered_map<int,bool> visited;
```

* Keeps track of nodes that have been visited at least once.

---

```cpp
unordered_map<int,bool> dfstr;
```

* DFS Recursion Stack.
* `true` → node is in the current DFS path.
* `false` → node has finished processing.

# DFS Function

### Entering a node

```cpp
visited[node] = true;
dfstr[node] = true;
```

Meaning:

* Mark node as visited.
* Put it into the current recursion stack.

---

### Case 1 : Neighbour not visited

```cpp
if(!visited[j])
{
    bool x = dfscycle(j, visited, dfstr, adj);

    if(x)
        return true;
}
```

Go deeper using DFS.

If the recursive call finds a cycle, immediately return `true`.

---

### Case 2 : Neighbour already visited

```cpp
else if(visited[j] && dfstr[j])
{
    return true;
}
```

If the neighbour is

* already visited **and**
* still present in the current DFS recursion stack,

➡️ **Back Edge Found** → **Cycle Exists**.

---

### Leaving a node

```cpp
dfstr[node] = false;
```

Remove the node from the recursion stack because its DFS is complete.

---

### No cycle found

```cpp
return false;
```

# Handling Disconnected Graphs

```cpp
for(int i = 0; i < n; i++)
{
    if(!visited[i])
    {
        if(dfscycle(i, visited, dfstr, adj))
            return true;
    }
}
```

Run DFS from every unvisited node because the graph may have multiple disconnected components.

## ⭐ Easy Memory Trick

* **visited** → "Have I ever visited this node?"
* **dfstr** → "Is this node in my current DFS path?"
* **visited && dfstr == true** → **Back Edge → Cycle**
* Before returning from DFS → `dfstr[node] = false` (remove from current path).
